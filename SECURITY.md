# Security Policy

## Supported Versions

Only the latest release of G-rizzle receives security fixes.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, open a [GitHub Security Advisory](https://github.com/sofired/grizzle/security/advisories/new). This keeps the disclosure private until a fix is ready.

Include as much of the following as possible:

- Type of vulnerability (e.g. SQL injection, path traversal, privilege escalation)
- File paths and line numbers relevant to the issue
- Steps to reproduce
- Proof-of-concept or exploit code (if possible)
- Potential impact

You can expect an initial response within 5 business days. If the issue is confirmed, we will work on a fix and coordinate a disclosure timeline with you.
